## 4. 哪些仍静态，哪些条件会看不到动画

- 原背景是同一批静态world/away图片：无局部背景复制image/mask、无流水/花叶/海浪覆盖、无额外旋转钟针。原画水、石头、房屋、船、花草不会随装饰运动。
- 植物种植/装置状态的旧sprite可能仍有旧循环动画，动物旧漫游和云影也沿用；不要把“背景静态”误写成“整个游戏没有任何其它动画”。减少动态规则额外停止旧植物/齿轮/知识光点，保持图案可辨。
- 系统`prefers-reduced-motion:reduce`时整套.scene-ambient隐藏；这是尊重偏好，不是加载缺失。弹窗打开时装饰暂停；进入远行时主场景隐藏并暂停。当前用户是否处于这些状态未知。
- 主场景最多两只、低饱和色，可能在视野边缘。此前几何证据仅保证若干居中全景画布至少一条路线完整可见，不涵盖任意拖动和缩放。
- 按相机公式，360×280场景里蝴蝶控制点宽度上界约11屏幕像素，翼缘描边约0.18屏幕像素；这些是几何估算，不是实际屏幕测量。小生物是否在繁复原画里足够醒目仍需真实观察，不应盲目加密度或仅凭静态检查说“明显”。
