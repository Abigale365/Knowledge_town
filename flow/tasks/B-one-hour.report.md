# B 一小时：教学变化可达性只读核查

日期：2026-10-23 America/Los_Angeles。本轮截止12:20:04 UTC。范围仅核查实际入口、B4/B5首节差异及门禁提示，不改冻结知识/教案/摘要、游戏源码或发布。本轮只写本报告；无新增Goal，沿用该限时专项范围。共享额度读取usedPercent4、剩余96%，未触发提前收尾。

## 实际结论

当前dist在**全新存档**的脚本初始化模拟中已默认进入B5原课程首节：revision5、课程ID `course-87vtar`、22项基础。不能据此认定用户仍在旧版，也不能据源码已接线就认定用户已看到变化。旧B4银行保留revision4，未自动升级；B5初始仍是寻物/基础界面，完整示范要在全部基础按顺序确认后才出现。场景美术及第一轮仍是排序，因此玩家浅层试玩很容易感觉没有变化。

实测B4首节8轮含 `repair-mapping` edit四槽抄代码；B5首节8轮含 `inspect-model-work` matrix职责/参数判断，旧四槽不存在。第一轮从 `assemble-method` 改为 `build-an-executable-method`，但两者都是order控件，最明显差异在**示范→引导后进入第二轮矩阵**。AIB首节则是4份知识、4轮，不能用它的短路径说明原课程22份知识。

## 玩家可复现入口和阶段

1. 原B4银行仍选中时，章节面板出现“进入新版教学5（旧课程和进度保留）”（`openTeachingV5`）；点击应进入独立B5银行，旧进度保留。若课程没有教学策略，先显示“开启新版探索课程（旧进度保留）”，其运行默认参数现在同样选择legacy5。不要删除旧档来测试。
2. 原课程B5进入本节学习工坊/整理柜，知识列表依序查看并“确认基础”。未完成22项时 `openTaskWorkshop()` 仍返回基础面板；最后一项确认后点击“继续本节示范与练习”，显示推理示范（`b5DemoDone`）。点击“已看过推理，进入引导练习”，显示引导题（`b5GuidedSubmit`）；完成后才进入独立应用（`workshopSubmit`）。该门禁不是收藏数量门禁，预览/收藏不应替代确认或应用。
3. 顶部“导入知识库”→“预览完整课程（教学5）”是AIB整套课程预览，需服务 `/api/aib-course`、预览确认后加入课程；这条路径的首节只有4项基础。它和默认原课程B5是不同银行，不能作为无服务也一定可用的唯一入口。
4. 提前微判断入口由随身栏 `b5MicroTray` 提供，当前统一文案“学完这一组，轻松试一试”，不在基础面板的主要继续按钮处。原1.1首个微判断要求sourceUnitId为 `1.1-lesson-1`（算法）和 `1.1-lesson-2`（模型）；它们在运行知识列表实际是第8、9项、运行ID分别 `1.1-lesson-8/9`。列表前两项是AI/ML，读完它们不开放该题，不能把此现象误报为先修校验错误。

## 关键复现：预览后微判断入口刷新滞后

用现有 `tests/town-harness.cjs` 加载当前dist和完整脚本顺序：`openTeachingCourse('legacy5')`；按sourceUnitId找到算法/模型两项，对两项调用 `openStudyLesson(id,true)`；关闭窗口。此时两项已写入viewed，当前阶段仍foundation，**微判断按钮数量0**。再调用 `renderTray()`，按钮数量变为1，文案“学完这一组，轻松试一试”。即知识条件已满足但这条预览返回路径没有刷新入口；不是需要收藏或读完22项。

源码对应：`teaching-flow-ui.js`的openStudyLesson在打开时写viewed；`teaching-v5-ui.js`只在renderTray时计算微判断可用性。此结论限当前dist与模拟事件链，真实浏览器刷新时机仍需D/C验证，不将模拟DOM当视觉验收。

## 最多三项建议，供D集中接线

1. **让当前银行/版本和升级动作始终可辨认**：在B4/旧库入口显式标“旧课程，新增示范与矩阵在B5”，提供保留旧档的一步进入按钮；B5标当前版本与当前阶段。不要静默把旧通过迁成新理解证据。首节差异提示应具体到“示范、引导、第二轮参数判断”，不能只显示“已更新”。
2. **使已有微判断及时、就近可达**：知识预览关闭/返回后更新可用入口；在已读算法/模型旁显示带主题名的可选练习入口，不仅藏在随身栏。按sourceUnitId映射，不把运行顺序ID误当知识ID；可指引自由查看这两项后先试题，避免必须顺读到第9项才知道能练。保持先教知识、可选、不记独立掌握，不修改冻结微判断数据。
3. **按阶段给准确下一步，别把阶段藏在“应用工坊”之后**：基础面板显示“还需确认哪些知识→示范→引导→独立应用”；就绪后直接给示范按钮。当前找齐提示仍说“读完放柜，继续应用工坊”，而B5事实上先进入示范/引导，建议D更新运行提示及当前阶段状态，保留90%章后正式测验与先修规则。
