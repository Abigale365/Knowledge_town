# 知识副本 · 失落的档案馆

当前版本 v0.11：六个独立章节都可直接进入、交替游玩并保存各自进度。四个学习章节按13个小节组织课程，先阅读基础知识，再提交知识成果解锁本章练习、复习和错题；章末完整测验达到90%记为本章通关。海边与圣诞章节各有三项顺序冒险任务，不含课程题目。启动方式与接口配置见 [课程使用说明](COURSE_SETUP.md)。

学习装置按内容变化：术语图鉴、方案工具台、实验手册、战略沙盘、价值账本、竞争画布、责任原则板、治理档案柜、风险图板、组织仪表、数据搭建台、协作圆桌和转型路线。果篮只是设计思路的例子，并未作为统一玩法。

## v0.10 物件承载答案与场景事件

学习候选以地图、药瓶、书本等实际物件呈现。点击可以读到对应题目和候选内容；取走后出现在“答案物品”栏，可拖到本题装置，也支持点选物件后点击装置。直接从场景拖入亦可，放错位置不会丢失答案。普通道具收集先完成关联课程练习，组合产生的奖励物品继承知识关联，旧存档道具首次使用会补入学习事件。

通用邮差复习保留题目的语义：概念逐项配对、分类投递、多个答案选择、步骤排序、净节省或ROI输入计算。原文参考支持安全的表格与段落展示。使用提示或修正后的练习单独标记，答对立即保存物品，不依赖关闭结果窗口前再点一次按钮。

新增模块：`encounter-rules.js`、`learning-interactions.js`、`scene-learning.js`。验证命令：`node tests/learning-interactions.cjs`、`node tests/scene-learning.cjs`。前者遍历现有200题并检查复杂复习，后者验证物件背包、错放、拖入与恢复；两者均为模拟DOM测试。Windows静态审计使用 `python -X utf8 tests/static-audit.py` 和 `python -X utf8 tests/world-hit-audit.py`。桌面和390px浏览器检查已执行，真机触摸尚未验收。

v0.3 中文点击解谜冒险：从有身份、事故和目标的开场出发，经不计分的操作教学，进入四个独立地点调查与修复，最后获得明确结局。

## 一局怎样玩

打开 `dist/index.html`。点“开始冒险”，按当前目标与米拉交谈、读练习信、选择帮手并试做。进入正式冒险后，地点中的物件可检查和操作；右侧回应会解释后果，底部（小屏顶部）的目标提示下一步。四处修复完成即可点亮塔灯。

四个地点：档案馆找证据并逐封处理委托；维修工坊在机器上交换步骤牌并接通权限检查；试验花园调节使用人数和人工检查，看场景与读数变化；试炼塔在新情境中选择两项可靠行动。每处修复都会获得进入下一处的徽章。

## 运行与检查

纯HTML/CSS/JS，不需要安装运行依赖，无外部CDN、模型密钥或在线模型调用。

```
node --test tests/engine.test.cjs tests/journey.test.cjs
node tests/ui-smoke.cjs
python3 tests/static-audit.py
node --check dist/app.js
```

状态规则18项检查、两个章节的模拟完整交互，以及静态资产、场景比例与指定文字对比度检查。模拟DOM不是实际浏览器交互验收。发布后另行检查平台产生的首屏快照。

## 架构与边界

`engine.js`管理知识规则、收益模型和正式表现；`journey.js`管理调查、证据、教学、门锁与事件；`app.js`管理开场、场景、对话和操作；`materials.js`提供经过核对的结构化内容包导入。五张独立手绘场景图为游戏背景，热点、步骤牌和条件反馈由代码控制。

当前是有完整开始和结局的短篇机制原型，不是完整商业RPG。NPC对话预先编制，没有实时自由对话、任意教材自动生成或学习效果验证。数值为明确标注的教学假设；素材结构校验不代表知识真实性校验。新版内容包使用独立ID，避免旧版存档跳过新教学。

## v0.4 林间寻物社

首页为寻物委托原型：2 张场景，3 类任务，每轮 12 件独立物品、3 份有效证据；同类物件二选一，点击后阅读再决定收取或排除。场景可放大至 300% 并拖动，支持方向键移动和区域提示。重开改变摆放与首轮委托条件，自动保存本局。原版完整冒险在 `adventure.html`。

逻辑：`hunt-engine.js`；交互：`hunt.js`；样式：`hunt.css`。没有构建步骤。新增任务在 make() 的模板中维护，当前尚不是任意知识库自动生成系统。

验证：`node --test tests/engine.test.cjs tests/journey.test.cjs tests/hunt.test.cjs`、`node tests/ui-smoke.cjs`、`node tests/hunt-ui.cjs`、`python3 tests/static-audit.py`。UI 测试是模拟 DOM，不等于真实浏览器或手机测试。

物件图集：`dist/assets/objects.png`，使用内置图像生成工具生成透明 4 列 3 行画风统一的古典文具与装饰品，完整生产提示见 `research/v04_寻物玩法计划.md`。原场景沿用。

## v0.5 星叶群岛

首页为八站连续寻物冒险。八张不同原画、90 处可检查实物、三种机制（证据筛选、十选四、四份卷轴补全）、31 枚永久知识收藏、每关最多三星。地图逐关解锁，重玩可改善最佳星级，保留收藏与道路；未完成关卡可续玩。组合题支持原画物件拖入缺口及点开后放入；放大至 400%、拖动、键盘移动、区域提示、沉浸查看和行走角色。

`expedition-engine.js` 负责题目、关卡锁、星级和存档校验；`expedition.js` 负责交互；`expedition.css` 负责呈现。点击区域对准原画中已经画好的物件，不把贴纸叠到场景里。新场景为内置图像工具生成，WebP 为相同画面的压缩导出，地图用独立缩略图减少首屏下载。

本机存档键 `kq-expedition-v2`，前一版短局与原冒险分别保留独立存档、入口。收藏与星星属于当前浏览器，没有服务器账户同步、多人排行榜或任意知识库自动生成。

新增验证：`node --test tests/expedition.test.cjs`、`node tests/expedition-ui.cjs`；后者是模拟 DOM 事件流程，不能替代浏览器与手机实测。详细记录见 `research/v05_八站寻物冒险.md`。

## v0.6 拾知小镇（当前首页）

从有限八关调整为可持续使用的个人学习空间。用户 TXT/Markdown/CSV/JSON 材料与手动学习卡进入独立材料库，确认题目与原文后生成实际寻物候选；材料会真正改变问题、答案与回收内容。没有后台模型调用，普通笔记是原文提取候选；复杂 AI 出题提供含原文的提示词及 JSON 回导。

主流程：探索原画实物→收集有用答案/回收无关答案→配对归档→结算→到期/新知识下一批。各材料保存独立未完成批次，没有八关终点。四位移动伙伴分别提供材料管理、复习、道具合成与主题植物；纸能合成可定位线索的罗盘，学习币能交换种子。

`learn-parser.js` 负责文本/题库提取；`learn-engine.js` 负责状态、复习调度、材料与资源；`world.js`/`world.css` 负责两处连续世界与交互。全静态，无构建步骤。存档键 `knowledge-town-v3`，本机保存并可导出/恢复。支持 1000 题；大型素材需拆分，浏览器存储不足时会提示导出备份。

新增检查：`node --test tests/learning.test.cjs`、`node tests/world-ui.cjs`，模拟 DOM 不替代浏览器与手机实测。完整记录及生成提示词见 research/v06_持续学习小镇.md 和 v06_美术提示词.json。
