# 拾知小镇 · Knowledge Town

把学习资料变成一场可以探索、收集、整理和复习的游戏。当前版本：**v0.12**。

## 开始运行

需要 Node.js 22 或更新版本，无需安装依赖或构建。

```sh
node server.cjs
```

打开 http://127.0.0.1:8766/ 。第一次进入会出现游戏指导；顶部“玩法指南”可随时重开。

## 现在可以玩什么

| 内容 | 入口 | 状态 |
| --- | --- | --- |
| 拾知小镇：四个学习章 | `dist/index.html` → 六章地图 | 当前维护，章节自由进入、章内按顺序学习 |
| 贝壳来信湾、铃铛不眠街 | 同上，第五、六章 | 当前维护，场景机关、可选支线与独立存档 |
| 失落的档案馆 | 其他冒险 → 档案馆 | 保留的独立游戏，调查与修复剧情 |
| 星叶群岛 | 其他冒险 → 群岛 | 保留的独立游戏，八站探险与收藏 |
| 林间寻物社 | 其他冒险 → 寻物社 | 保留的独立游戏，证据寻找短局 |

基础知识藏在齿轮、苗圃、镜片、来信、地图和星轨等物件里。原场景道具始终可查看，未解锁时提示“暂未开始”；全章基础整理交付后，再开启练习、复习和错题。本章测验90%算通关，其他章节始终可以进入。

## 仓库怎么找

| 目录/文件 | 放什么 |
| --- | --- |
| `dist/` | 当前可玩的前端、经典游戏及共享素材；这是实际维护的运行目录 |
| `server.cjs`、`.env.example` | 本地课程生成服务与配置模板 |
| `content/` | 学习大纲、来源资料、题库原料 |
| `scripts/` | 构建资料、仓库完整性检查、当前测试入口 |
| `tests/` | 当前测试、经典游戏测试与仍有用途的兼容检查 |
| `docs/` | 当前使用、测试、结构和美术说明 |
| `archive/` | 旧计划、旧报告、历史快照与退役实验，保留供查阅 |
| `artifacts/` | 本机临时产物，忽略上传 |

详细分类与迁移记录见 [仓库导航](docs/REPOSITORY.md)。旧资料不会再混进当前首页说明。

## 接入自己的资料

复制 `.env.example` 为 `.env`，填写服务地址、模型和密钥，重新启动。支持兼容 Chat Completions 的可配置接口；生成内容先预览、核对后加入课程。未配置接口时，内置课程和独立游戏照常可玩。密钥仅由本机后端使用。

[完整玩法与接口配置](docs/GAME_GUIDE.md) · [测试说明](docs/TESTING.md) · [课程原料](content/README.md) · [历史归档](archive/README.md)

## 检查

```sh
node scripts/check-repository.cjs
node scripts/test-current.cjs
```

测试包含逻辑、模拟DOM和经典游戏回归。模拟DOM不等同于真实浏览器或真机触摸验收；实际浏览器检查范围见测试说明。
