# 拾知小镇 · Knowledge Town

把学习资料变成一场可以探索、收集、整理和复习的游戏。当前版本：**v0.16**。

## 开始运行

需要 Node.js 22 或更新版本，无需安装依赖。仓库自带已构建的游戏；修改源码后运行 `npm run build`。

```sh
node server.cjs
```

打开 http://127.0.0.1:8766/ 。第一次进入会出现游戏指导；顶部“玩法指南”可随时重开。

## 现在可以玩什么

| 内容 | 入口 | 状态 |
| --- | --- | --- |
| 拾知小镇：四个学习章 | `dist/index.html` → 六章地图 | 当前维护，章节自由进入、章内按顺序学习 |
| 贝壳来信湾、铃铛不眠街 | 同上，第五、六章 | 当前维护，场景机关、可选支线与独立存档 |
| 失落的档案馆 | 其他冒险 → 档案馆 | 保留的独立游戏，调查与修复剧情 |
| 星叶群岛 | 其他冒险 → 群岛 | 保留的独立游戏，八站探险与收藏 |
| 林间寻物社 | 其他冒险 → 寻物社 | 保留的独立游戏，证据寻找短局 |

内置课程含139个中英文知识单元。先阅读、收集或从场景寻找部件组装，再使用本节装置解决实际情境，才能完成小节。仅任务1.1使用术语配对；其余12节包含预算分配、收益核算、权限配置、数据修复等42轮操作。整章基础交付后开启练习、复习与错题，章末测验90%算通关。右上角可选择中文、English或中英双语；双语模式同时显示两种文字，六章均支持独立重玩。学习阶段只出现本轮知识物件与学习装置；基础交付后刷新答题和场景事件，答案物件与普通工具不会共用图标。知识图案缩小至约40px，保留60px透明点击范围。

课程生成先建立知识库、核对来源与缺口，再生成游戏章节，详见[知识与交互设计](docs/KNOWLEDGE_DESIGN.md)。

## 仓库怎么找

| 目录/文件 | 放什么 |
| --- | --- |
| `dist/` | 保持原路径的发布副本、经典游戏及共享素材；手工源码已迁至 apps/game/src |
| `apps/game/`、`apps/server/` | 游戏源码和服务实现；根 server.cjs 保留启动兼容 |
| `packages/` | 知识、教学设计、共享契约和课程编译桥 |
| `flow/tasks/` | A/B/C 开发任务卡、接口边界及 D 集成交接 |
| `server.cjs`、`.env.example` | 本地课程生成服务与配置模板 |
| `content/` | 学习大纲、来源资料、题库原料 |
| `scripts/` | 构建资料、仓库完整性检查、当前测试入口 |
| `tests/` | 当前测试、经典游戏测试与仍有用途的兼容检查 |
| `docs/` | 当前使用、测试、结构和美术说明 |
| `archive/` | 旧计划、旧报告、历史快照与退役实验，保留供查阅 |
| `artifacts/` | 本机临时产物，忽略上传 |

详细分类与迁移记录见 [仓库导航](docs/REPOSITORY.md)。旧资料不会再混进当前首页说明。

## 接入自己的资料

右上角“导入知识库”可选择或拖入多份文字文件，也可直接粘贴正文；清单支持追加、替换同名文件和移除，最多50份、合计7MB。PDF或扫描件需先提取文字。

复制 `.env.example` 为 `.env`，填写服务地址、模型和密钥，重新启动。支持兼容 Chat Completions 的可配置接口；生成内容先预览、核对后加入课程。未配置接口时，内置课程和独立游戏照常可玩。密钥仅由本机后端使用。

## 检查

```sh
node scripts/check-repository.cjs
node scripts/test-current.cjs
```

测试包含逻辑、模拟DOM和经典游戏回归。模拟DOM不等同于真实浏览器或真机触摸验收；实际浏览器检查范围见测试说明。

后续并行开发的模块边界、知识包/学习方案接口草案及可复制任务说明见[模块拆分方案](docs/MODULE_BOUNDARIES.md)。

## 多对话开发

拆分已落地；请从 [任务入口](flow/tasks/README.md) 分别开启 A 知识库、B 教学设计、C 游戏体验对话。当前对话 D 负责最后集成。共享接口见 [pipeline v1](docs/contracts/pipeline-v1.md)，目录说明见 [模块边界](docs/MODULE_BOUNDARIES.md)。知识和教学适配器已能用固定样例贯通，但通用内容生成算法仍是 A/B 的后续任务。

`npm run build` 将模块源码发布到原 dist 路径，不清空素材；`node scripts/test-current.cjs` 验收模块、原入口、存档和经典游戏。C 使用 `node scripts/build-game.cjs --out artifacts/previews/game-C` 与 `node scripts/preview-game.cjs --dir artifacts/previews/game-C --port 8773` 独立预览。
