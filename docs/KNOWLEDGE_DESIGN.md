# 知识先行的学习交互

## 内容清单与来源

内置课程按大纲的四章、13 个 Task、58 项技能组织。`content/knowledge-inventory.json` 是可审阅的知识清单：76 个单元逐一记录所属任务、技能、术语、定义、示例、英文释义、出处和交互方式。游戏由同一清单构建，不用装饰按钮数量充当知识覆盖率。

Task 1.1 包含 22 个单元，按“AI领域与学习方法”“模型与运行机制”“数据形态”“数据质量”“验证与泛化”“词汇与标准”分组。先学习 AI、ML、深度学习、神经网络、NLP、计算机视觉和生成式 AI，再理解算法、模型、训练、推理，以及数据和验证。单元标识保持稳定，重排不丢失原有收集记录。

原有教学释义与例子依据用户大纲和伴读资料编写；新增基础概念查阅了 [IBM AI](https://www.ibm.com/think/topics/artificial-intelligence) 和 [IBM Machine Learning](https://www.ibm.com/think/topics/machine-learning)（2026-10-20）。[NIST AI RMF](https://airc.nist.gov/airmf-resources/airmf/0-ai-rmf-1-0/) 用于核对 AI 系统与风险治理的概念边界。ISO框架条目另外核对了[ISO/IEC 42001](https://www.iso.org/standard/42001)与[ISO/IEC 23053](https://webstore.iec.ch/en/publication/77056)的官方简介。它们不是官方考试题库。覆盖所有列出的技能，不代表已经穷尽考试可能涉及的知识；其他任务的教学补充仍需持续由领域人员审阅。

## 学习与理解检查

1. 阅读型物件直接展示定义与示例，读完可收集。
2. 组装型物件提示寻找部件；返回场景后出现这件物品的三个部件，每个可展开阅读。收集后可拖放到插槽，也可先选部件再选插槽；放错不消耗素材。不同物品分别使用齿轮、匣壳、摇柄，种子、陶盆、水壶，镜片、镜筒、镜柄，或罗盘部件。
3. 将知识物件交付本节装置。计数为已整理知识单元数/本节总数。
4. 收齐后打开概念—定义配对。两列独立打乱，每页最多五组。错误可重试，正确配对持久保存，切换章节和刷新不会清除。
5. 所有概念配对正确，才允许完成小节、收好装置并刷新下一节。整章基础交付后才开启正式练习、复习、错题和90%章末测验。

配对是读完后的形成性理解检查，不是要求初学者先答题才能看到知识。知识素材箱始终允许重读已收集的内容。

## 双语与重玩

右上角“中文 / EN”切换当前小镇界面、内置学习内容和内置200道练习的显示语言。题干、选项、配对、流程、填空和情境文字有对应英文；翻译仅影响显示，不改变判分用的标识与答案，语言选择自动保存。三个经典独立游戏保留原版中文界面。用户手工导入且没有英文版本的原始资料保留原文，不以未经核对的翻译替代。

六章分别有重玩入口，游戏内说明重置范围并要求确认。学习章重置本章收集、配对与章末成绩；冒险章重置本章主线与风景手帐。其他章节不变。

新增知识后，曾完成旧版 Task 1.1 的存档会保留已读与已整理素材，将旧成绩保存在历史字段 `previousResults`，重新开放这个小节以补充新知识；其他章节保留。

## 自定义课程流水线

配置本机API后，每个材料片段依次执行两次模型调用：

1. **建立知识库**：提取明确知识单元、定义、引用、出处、中英文内容，并报告只列目标却缺少解释的缺口。逐字引用必须在上传片段中核对成功。
2. **编排课程与交互**：以已核实知识库组织四章、学习卡与练习；最终逐项核对每个单元的标题、定义和引用是否保留。缺口未补、引用不实、内容改写或条目遗漏都会阻止加入游戏。

当前后端不会自动联网抓取补充资料。若上传文件只是大纲，应补充教材、讲义或权威资料正文；不能让模型把未经查证的信息伪装成材料内容。生成结果仍需用户预览核对后才加入，API密钥仅存在本机环境变量。

## 维护

```sh
python scripts/build-chapter-course.py
python scripts/build-aib-pack.py
node scripts/build-i18n.cjs
node scripts/test-current.cjs
```

基础课程脚本会调用 `enrich-knowledge.cjs` 和 `build-i18n.cjs`，一并更新课程、知识清单与语言数据。题库重建后需重新构建语言数据。英文知识原料在 `knowledge-english.tsv`，英文题目原料在 `practice-english.tsv`，界面词条在 `interface-english.json`。
