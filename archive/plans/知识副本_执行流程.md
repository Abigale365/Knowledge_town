# 知识副本：研究、验证与 Demo 执行流程

建立日期：2026-10-19。负责人：本项目助手。用户授权：自主研究、实现、自检，遇到阻断问题再询问。

## 目标与边界

把可靠学习材料转为一局可操作的学习冒险。以 AWS AIB-C01 英文备考为第一案例，验证知识能否进入决策、操作和后果；不以动画覆盖选择题。固定游戏引擎，内容包独立，知识判定与叙事分离。

比赛暂按此前讨论的第六游戏赛道定位；当前线程没有比赛原始页面，具体规则与提交资格尚未重新核实，不把它作为已核实事实，也不阻断产品研究。

## 首轮假设与取舍

1. 优先学习“AI方案选择与业务价值”，因为能转成受约束的行动，而不是记忆孤立术语。
2. 小型学院/任务站复用地图；先实现空间探索与交互，不追求自动生成任意3D世界。
3. 材料转换必须显示来源与生成边界。不支持的材料应拒绝或要求完整结构，不能偷偷套用无关内容。
4. 无可用模型运行时，不冒充实时 AI。仍完成可玩的离线机制 Demo，明确标为预先编制内容，并提供后续模型接入结构。
5. 升级记录任务表现，不宣称单局即可证明掌握或提高考试成绩。另设变式挑战与未来延迟复测。

## 阻断与继续规则

常规设计、实现路线、功能缩减由助手决定并写入日志。缺少比赛规则、无法获取付费工具、缺少API凭据不应阻断机制验证；先完成现有条件可实现的版本并如实标注。只有涉及用户必须提供的资料或授权、且无合理替代时询问。

## 本轮放行结论

放行为“可配置学习冒险机制Demo”，供用户试玩，不放行为“任意材料自动生成学习游戏”。后续主线：真人试玩→片段级知识核对→真实模型生成实验→带依据的NPC自由问答→延迟迁移验证→必要时升级3D。比赛原文缺失、在线模型凭据缺失未阻断本轮Demo；未删改原有项目。
