# 历史归档：保留，但不作为当前使用入口

这里的内容用于追溯设计、实验和验证过程，不是当前游戏的启动目录。

- `plans/`：旧版研究、迭代计划和执行记录。
- `reports/`：已经结束的测试结果与历史输出；保留其原始时间和结论。
- `reports/runtime/`：此前误放在运行目录、但已入库的旧运行摘要。体积较大的旧状态检查点只保留本机副本，不再入库。
- `history/`：整理前的README、被取代的运行与上传说明。
- `prototypes/world-v06.html`：v0.6 首页源码快照，只作对照；实际游戏请从 `dist/index.html` 进入。
- `experiments/*.cjs.txt`：旧长跑/监控脚本原文，部分含固定过期日期、旧报告位置或旧失败基线。改为文本归档，不纳入当前测试执行。
- [file-moves.json](file-moves.json)：旧位置、新位置和迁移原因。

**失落的档案馆、星叶群岛、林间寻物社属于仍然可玩的正式独立游戏，保留在 dist 中，没有放进历史归档。**

历史文档中出现的路径和“当前首页”等字样代表当时版本，请看 [当前仓库导航](../docs/REPOSITORY.md) 和 [当前测试说明](../docs/TESTING.md)。
